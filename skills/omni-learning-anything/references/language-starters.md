# Six beginner routes for a first independent exchange

Choose the row for the learner's **target** language. Explain each step through their stated teaching language. Each row is an Omni-authored sequence of four small tasks with an entry point for checking usage or finding audio. Open the relevant unit before using it. Pace the tasks over as many lessons as the learner needs. A title, catalog or sign-in page supplies no transcript.

| Target and starting situation | Four linked tasks | What to contrast with the learner's language | Independent exit task and source |
| --- | --- | --- | --- |
| Japanese · first day in a class | Choose a greeting for the time and relationship → introduce yourself → ask for repetition → respond to a changed introduction | Keep kana beside new forms. For a Chinese reader, compare the sound and use of a familiar-looking expression with the Japanese example. For a reader new to kana, teach a short sound-to-script segment first. | Pick a greeting for a teacher and introduce yourself. When the next turn is unclear, ask for repetition using a practiced expression. Irodori Starter has lesson PDFs and audio. [Japan Foundation](https://www.irodori.jpf.go.jp/en/starter/pdf.html) |
| English · meeting someone | Notice the greeting and name → exchange introductions → check a name you missed → introduce one person to another | In a language that often omits subject pronouns, highlight the subject and verb of a short English introduction. In a familiar alphabet, focus on how the written name sounds. | Read or listen to a new introduction, reply appropriately and check one detail. Match the result to the modality actually used. [British Council A1 speaking](https://learnenglish.britishcouncil.org/free-resources/speaking/a1) |
| French · first meeting | Greet someone → ask and give a name → select a form of address for the setting → close the exchange | Contrast tu and vous with the learner's actual address system. Segment one short verified recording, then match the sound to the written words. | Introduce yourself to an unfamiliar person in a specified setting and respond to a follow-up using the register taught. [TV5MONDE Première classe](https://apprendre.tv5monde.com/en/exercices/premiere-classe) |
| Spanish · ordering refreshments | Identify menu items → ask for one → specify the quantity → clarify an order when a detail changes | Keep the noun, its article and quantity together. Compare agreement or word order with an actual example from the learner's language. | Order two items from a short unseen menu made of familiar words, then correct one detail. [The Open University, food and drink](https://www.open.edu/openlearn/languages/spanish/beginners-spanish-food-and-drink/content-section-0?intro=1) |
| German · registering for a class | Greet someone → give a name → spell or confirm a detail → answer a short registration question | Pair each model question with its answer and mark the finite verb position. Select a polite or familiar form appropriate to the original exchange. | Complete a short registration exchange with one request for clarification, then check that the typed name matches. Use the official practice units that fit the learner's goal. [Goethe-Institut elementary practice](https://www.goethe.de/de/spr/ueb/ele.html) |
| Korean · reading a name and making an introduction | Identify a small set of Hangul letters → assemble familiar syllable blocks → read a name in context → use a practiced polite introduction | Show consonant and vowel placement inside one syllable block. Adapt the amount of romanization practice to the learner's existing script knowledge. | Read a short unfamiliar combination built from taught letters and introduce yourself with an appropriate ending. Check actual unit access and audio availability. [Online King Sejong Institute curriculum](https://www.iksi.or.kr/lms/main/curriculum.do) |

For another target, use the same four decisions: select a real situation, establish the script/sound prerequisites, locate authoritative beginner input in the requested variety, and choose an exit task achievable without a phrase bank. Later blocks can revisit the same language function with less translation, a different partner or a longer authentic passage.
