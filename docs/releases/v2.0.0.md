# v2.0.0 — 多格式与云文档交付

学习内容现在可以交付到 Markdown、DOCX、PDF，以及 Notion、Obsidian、飞书、腾讯文档、钉钉。未声明平台或缺少授权、目标位置时，Skill 会通过简短的多轮对话补齐所需信息。

## 本次更新

- 新增独立 Markdown 和带图片的 DOCX 导出；保留 PDF 与组合导出。
- 新增 Notion API、Obsidian Vault、飞书导入、腾讯文档导入和钉钉官方 dws CLI 路径，并提供已有连接器或经过验证的手动导入流程。
- 保存远程文档与任务标识，支持异步导入恢复、结果回读和重复交付保护；交付未确认时不会自动推进课程。
- 按所选格式检查依赖，复用已确认的偏好与授权引用，兼容既有 PDF 课程。

## 验证范围

- 自动化测试：77 项通过，0 失败。
- 中英文 Markdown/DOCX 实际生成、图片与链接检查及渲染检查通过。
- 实际 Obsidian Vault 文件与附件写入、回读、重复交付检查通过。
- 安装包已通过独立解压、脚本编译、版本、doctor、引用文件及 SHA256 校验。

**云端真实账号验收尚未完成。** Notion、飞书、腾讯文档和钉钉当前通过 API/CLI 合约测试；未将模拟测试标记为真实账号成功。Obsidian 原生客户端显示与跨设备同步也尚未验证。详见[验证记录](https://github.com/ShawnRen57/omni-learning-anything/blob/v2.0.0/docs/release-validation-v2.0.0.md)。
