**v5.0** · اختر من بين 135 مصدرًا تعليميًا. تعلّم لغة أجنبية بشروح بلغتك الأم، مع تمارين وإجابات في ملف منفصل. يرافق كل رسم توضيحي جديد سؤال يوجّه انتباهك إلى التفاصيل المهمة. [دليل المصادر](../curated-learning-resources.md) · [أمثلة لتعلّم اللغات](../../examples/languages/README.md)

**اختر مقرراً جامعياً أو ابدأ بكتبك وأبحاثك. تعلّم بالوتيرة المناسبة لك، مع أسئلة قصيرة وملاحظات مفيدة ومراجعة، واحفظ دروسك في ملفات محلية أو مستندات سحابية.**

اختر مقررا مفتوحا أو كتابا أو مقالا أو محاضرة، أو ابدأ بموادك الخاصة. حدد هدفك والوقت المتاح وراجع الخطة قبل الدرس الأول.

ابدأ بعبارة **«أريد دراسة علم النفس الإيجابي في هارفارد»**. يحدد الوكيل المقرر الأصلي، ويستخدم المعلومات التي قدمتها، ويسأل فقط عن التفاصيل اللازمة للخطة.

| الميزة | الوصف |
| --- | --- |
| مسار شخصي | يحوّل اهتمامك أو هدفك إلى مقرر يناسب مستواك ووقتك. |
| دليل المصادر | يضم 67 مسارا دراسيا و68 مصدرا إضافيا. يمكنك الرجوع إلى أصل كل مقرر أو كتاب أو مقال أو محاضرة ومعرفة شروط الوصول إليه. |
| لغة أجنبية من الصفر | تعلّم عبارات تناسب موقفا محددا وتدرّب على تذكرها في الاتجاهين. تحصل على أوراق مراجعة تراكمية وملف مستقل للإجابات. |
| كتب مدرسية صينية | ابحث في 1949 مدخلاً من الابتدائي إلى الثانوي. اختر كتاباً أو فصلاً أو مفهوماً أو صيغة، مع شرح مناسب للعمر ورسوم من الكتاب. |
| موادك الخاصة | اختر الصفحات أو الفصول أو المقاطع الزمنية في PDF أو DOCX أو EPUB أو PPTX أو HTML أو Markdown أو TXT أو SRT أو VTT. |
| المصادر والقراءات | ارجع إلى الصفحة أو الفصل أو التوقيت أو المصدر الموثق على الويب. |
| اعتماد الخطة | راجع موضوعات الأيام والوقت المتوقع قبل بدء الدروس. |
| قراءة الرسوم | أجب عن السؤال بقراءة التدريج أو تتبع سهم أو مقارنة مثالين متقابلين. لكل رسم مصدر يمكن الرجوع إليه. |
| عشر لغات | اختر لغة التعلّم بشكل مستقل عن لغة المصدر. يدعم العربية من اليمين إلى اليسار. |
| صيغ محلية | PDF وHTML للاستخدام دون اتصال وDOCX وMarkdown. |
| أماكن الحفظ | خزنة Obsidian محلية أو اتصال مرخّص مع Notion وFeishu وDingTalk وTencent Docs. |
| أسئلة قصيرة | أجب عن سؤال إلى ثلاثة في المحادثة أو البطاقات المدعومة. يمكنك طلب تلميح أو التجاوز أو الاستئناف. |
| ملاحظات على الإجابات | احصل على ملاحظات مستندة إلى المصادر، وعدّل إجابتك أو صحّح التقييم. |
| سجل التعلّم والمراجعة | راجع ضمن الوقت المتاح، واطلب ملخصاً أو صدّر الإجابات أو احذفها. |
| تعديل الخطة | راجع التغييرات المقترحة وفق أهدافك أو إجاباتك قبل إنشاء نسخة جديدة من المقرر. |
| Anki | صدّر أسئلة المراجعة بصيغة CSV لاستيرادها إلى Anki. |
| المتابعة والجدولة | استأنف من الدرس التالي. تستخدم الجدولة أدوات الوكيل المضيف. |
| التثبيت والتحديث | ثبّت المهارة وتحقق من اكتشافها في الوكلاء المتوافقين، واحفظ المقررات في مجلد منفصل. |

جلسة مدتها عشر دقائق تغطي خطوة صغيرة، ولا تعادل محاضرة أصلية كاملة أو المقرر كله. يظل عبء الدراسة الأصلي موضحاً؛ وتحتاج القراءات الطويلة والتمارين والمشروعات إلى وقت إضافي. قد تتغير المصادر وإمكانية الوصول إليها. هذه مسارات تعلّم مستقلة تعتمد على مصادر مقررات عامة، ولا تتضمن محتوى المحاضرات كاملاً، ولا تعني اعتماداً من الجامعات أو منح شهادة.

## تعلّم من موادك الخاصة

استخدم PDF أو TXT أو Markdown أو HTML أو DOCX أو EPUB أو PPTX أو SRT أو VTT. اختر الفصول أو الصفحات أو الطوابع الزمنية، وحدد السماح بالمراجع الإضافية. ترتبط الشروح والأسئلة بمواضعها الأصلية. تحتاج ملفات DOC وRTF القديمة إلى تحويل مسبق بأدوات موثوقة.

يمكنك البدء بفكرة عامة مثل «أريد فهم بعض الاقتصاد». يقترح الوكيل اتجاهات ويوضح افتراضاته ويسأل فقط عما يؤثر في الخطة. أما الهدف المحدد فينتقل مباشرة إلى التخطيط.

<a id="choose-your-learning-language"></a>
## اختر لغة التعلّم

<a id="quick-start"></a>
## التثبيت والبدء

اطلب من الوكيل تثبيت أحدث إصدار والتحقق من أن العميل الحالي يستطيع اكتشاف المهارة. احتفظ بالمقررات والاتصالات عند التحديث. إذا كان Node.js مثبتاً، نفّذ:

```sh
npx skills@latest add ShawnRen57/omni-learning-anything --skill omni-learning-anything -g
```

في Claude Code، استخدم مثبّت الإضافات:

```text
/plugin install omni-learning-anything --marketplace ShawnRen57/omni-learning-anything
```

دون Node.js، نزّل ملف ZIP أعلاه وارفعه عبر عميلك أو اطلب مساعدة الوكيل. قناة `skills.sh` متاحة؛ والإصدار المنشور حالياً في SkillHub هو v2.6.0. راجع دليل القنوات لمعرفة الإصدارات المتاحة.

## جرّب مقررك الأول

```text
اعرض المقررات المدمجة. استخدم مقرر Yale Death، ربيع 2007، مصدراً.
أنا مبتدئ. علّمني بالعربية لمدة 20 دقيقة يومياً.
حافظ على ترتيب الوحدات وأظهر عبء الدراسة الأصلي.
احفظ بصيغة HTML دون اتصال، واعرض الخطة أولاً.
```

أو جرّب: «علّمني أول فصلين من كتابي بصيغة EPUB في جلسات من 15 دقيقة»، أو «ساعدني على فهم المؤسسات المالية من Yale Financial Markets 2011».

راجع الخطة ووافق عليها ثم اطلب الدرس الأول. للاستئناف قل «تابع من أقدم درس لم يصلني بعد». يمكنك الإيقاف المؤقت. تتطلب الجدولة دعماً من المضيف واتفاقاً على الوقت والمنطقة الزمنية؛ يبدأ الإنشاء في الموعد، ويصل الدرس بعد البحث والمراجعة.

## الأسئلة والملاحظات والمراجعة

اطلب عند الحاجة من سؤال إلى ثلاثة أسئلة قصيرة على هيئة بطاقات أو نص. احصل على ملاحظات وتلميحات مستندة إلى المصادر؛ ويمكن طلب اختبار أطول. تُحدَّث سجلات التعلّم في الخلفية كي لا تقطع القراءة.

اسأل «ماذا أراجع اليوم؟» لمراجعة قصيرة ضمن وقتك المحدد، أو «ماذا تُظهر إجاباتي هذا الأسبوع؟» لملخص تدعمه الأدلة. يمكنك تصحيح تقييم أو استبعاد موضوع أو تفضيل درس جديد. لا تُنشئ المراجعة اختبارات تلقائية أو مؤقتات إضافية.

وافق على تعديلات الدروس المقبلة قبل بدء نسخة جديدة؛ تبقى الخطة السابقة والسجل متاحين. يمكنك تصدير بطاقات Anki بصيغة CSV باتجاه واحد، دون مزامنة تلقائية.
