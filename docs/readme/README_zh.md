**用中文上第一节日语课，花一小时读懂一场 TED 演讲，或用一个月精读一本书。从你想学会的那件事开始。**

把“我想学……”变成走得下去的学习计划。你可以从 135 个内置来源中挑选，也可以拿自己的书、论文或学校教材来学。先确认计划，再开始每日学习。

试试 **“我日语零基础，用中文教我，目标是第一次上课时能自我介绍”**，或 **“找一场关于讲故事的 TED 演讲，带我用一小时读懂它”**。

| 功能名称 | 功能简介 |
| --- | --- |
| 个性化学习路径 | 从一句想学的主题或明确目标开始，按你的基础、用途和可投入时间规划。 |
| 内置学习资源库 | 67 条已有学习路径，加上 68 个新来源。可按机构、主题和资源类型查找公开课、教材、学术书、深度文章及演讲。[浏览新增资源](../../docs/curated-learning-resources.md) |
| 用母语从零学外语 | 按真实场景学表达，练习看外语懂意思、看母语说或写外语。练习卷与参考答案分开，可混入前几课的内容复习。听辨支持原声或本机合成语音。[查看两套样例](../../examples/languages/README.md) |
| 中国大陆中小学教材 | 检索小学到普通高中的 1,949 条教材索引，支持「最新版」「2025 版」等说法。索引无法确认时，Agent 会查上游仓库并联网找原书。找到可核验的原书后，可按章节、概念或公式学习，引用教材原图与页码。 |
| 用自己的材料学习 | 导入 PDF、DOCX、EPUB、PPTX、HTML、Markdown、TXT、SRT 或 VTT，选择页码、章节或时间段，以及是否补充外部资料。 |
| 来源与扩展阅读 | 关键讲解可回溯到原书页码、章节、时间戳，或有核验日期和链接的网络来源。 |
| 先看计划再开课 | 先审阅每天学什么、预计花多久，确认后再开始生成课程。 |
| 教学配图与读图练习 | 新图附读图问题、可定位的观察线索和来源。比较图看对应关系，流程图顺着箭头找变化，教材图可对照原页观察细节。 |
| 十种学习语言 | 学习计划和材料的语言可独立于原资料选择，阿拉伯语支持从右向左排版。 |
| 四种本地格式 | 输出 PDF、内嵌图片的离线 HTML、DOCX 或 Markdown。 |
| 本地与云端保存 | 保存到 Obsidian 本地库，或授权连接 Notion、飞书、钉钉和腾讯文档。 |
| 学习短测 | 学完主动发起 1–3 道小题，通过对话或宿主支持的卡片作答，可要提示、跳过或续答。 |
| 答题反馈 | 对照学习来源说明哪里答对、哪里需要补一步，并给出下一步。支持补答或纠正判断。 |
| 学习记录与复习 | 用答题证据安排时长内的小复习、按需回顾学习情况，并可导出或删除答题记录。 |
| 学习计划迭代 | 根据新目标、时间变化或答题证据提出后续调整，确认后创建独立的课程版本。 |
| Anki 导出 | 把选中的复习题导出为 CSV，供 Anki 单向导入。 |
| 继续、暂停与定时交付 | 接着最早未交付的一课学，也可暂停和恢复。定时交付使用宿主 Agent 的能力。 |
| 安装与升级 | 在兼容的 Agent 中安装和检查技能发现状态，升级时将课程档案保存在技能目录之外。 |

## 选择内置课程与学习资源

可以按标题、主题或机构找资料。试试 **“推荐一场关于语言的 TED 演讲”** 或 **“带我学耶鲁的《现代诗歌》”**。选好课程、章节或讲座，再告诉 Agent 学习语言和可用时间，就能先审阅计划。

每天 10 分钟意味着完成一个小学习步骤，并不等于学完原课程的一整讲或整门课。原始学习量会明确标示，长篇阅读、习题和项目需要另留时间；来源内容与可访问性也可能变化。这些是依据公开课程来源编排的独立学习路径，不打包完整授课内容，不代表大学背书，也不提供大学证书。

## 用自己的材料学习

支持 PDF、TXT、Markdown、HTML、DOCX、EPUB、PPTX、SRT 和 VTT。可指定章节、页码或时间戳，并决定是否允许外部补充。讲解与自测会追溯到选定的原文位置。旧版 DOC、RTF 需先通过可信工具转换。

想法模糊也能开始，比如“我想懂一点经济学”。Agent 会提出可选方向，说明假设，只追问会影响课程的问题；目标清楚时则直接进入计划。

## 安装与开始

请 Agent 安装最新版本，并确认当前客户端能发现和使用技能。升级时保留已有课程与连接。已安装 Node.js 时可运行：

```sh
npx skills@latest add ShawnRen57/omni-learning-anything --skill omni-learning-anything -g
```

在 Claude Code 中使用插件安装器：

```text
/plugin install omni-learning-anything --marketplace ShawnRen57/omni-learning-anything
```

没有 Node.js，也可下载上方 ZIP，通过客户端技能上传或请 Agent 协助安装。`skills.sh` 已上线；SkillHub 当前上架版本为 v2.6.0。各渠道可用版本请查看渠道说明。

## 试着开始第一门课

```text
展示内置课程。以哈佛 CS50x 2026 为来源。
我是初学者，用中文教我，每天 20 分钟。
保留原单元顺序，标明原始学习量。
保存为课程文件夹中的离线 HTML，先让我确认计划。
```

也可以说：“用每天 15 分钟带我读这本 EPUB 的前两章”，或“用耶鲁《金融市场》2011 版帮我理解金融机构”。

确认计划后，请 Agent 开始第一课。回来时说“从最早未交付的一课继续”，需要时可暂停。只有宿主支持定时、且你确认时间与时区后才能安排自动执行；约定时间开始生成，完成检索与检查后交付。

## 轻量自测、反馈与复习

想检查理解时，可要 1–3 道卡片或纯文字小题。Agent 可以换一个情境、让你找出错误，或按学习目标选用原题和概念回忆。出题前会回查所选材料和页码，并重做一遍核对答案。可以说「用 Day01 教过的知识点给我一道新情境题，看看我能不能举一反三」。作答后可查看带出处的反馈和学习记录。

问“今天该复习什么”，可在已有时间预算内安排少量复习；问“这周的回答说明了什么”，可看到有依据的回顾。你能纠正判断、跳过主题，或优先学新课。复习不会额外创建自动测验或计时任务。

未来课程的调整先由你确认，再开启新版本；原计划与历史仍可查阅。还可按需单向导出 Anki CSV 卡片，不自动双向同步。
