# University course pathways v3.0.0 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development or executing-plans to implement this plan task by task. The user approved the linked design and publication; execute continuously without another execution-choice prompt.

**Goal:** Start a source-grounded personal course from a recognizable university course name, make discovery easy, and show real multilingual examples in all READMEs.

**Architecture:** Keep a compact versioned JSON catalog in the self-contained Skill; deterministic helpers retrieve and bind immutable pathway snapshots, while the agent researches and authors teaching content. Validate day-to-original-unit mapping with existing approval hashes and preserve legacy course behavior. Public examples and collage are repository artifacts, outside the installable bundle.

**Tech stack:** Python standard library helpers/unittest, existing PDF/HTML renderers, XeLaTeX, Pillow for assembling actual rendered pages, official university web sources, existing GitHub release tooling.
