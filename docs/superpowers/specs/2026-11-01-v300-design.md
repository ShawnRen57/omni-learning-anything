# v3.0.0：从知名高校课程快速开始

## 用户体验与方案

推荐采用“有来源的课程蓝图 + 每课按需核对原始材料”。用户说“我想学习哈佛积极心理学”，Agent 匹配 Harvard PSY 1504、Tal Ben-Shahar、Spring 2006，说明所据版本，沿原大纲顺序安排个人课程。只有会改变课程的同名歧义才追问；其余复用已知的语言、基础、每天时间和保存位置。具体目标优先，不强制展示推荐菜单。

相比“打包完整讲义”，课程蓝图更轻、便于校正，也不会冒充授课原文；相比“只联网搜索课程名称”，固定版本、来源及顺序更可靠。安装包内置的是学习路线和原课资料入口，Agent 按实际可读证据编写原创辅导材料，并清楚显示哪些是原课脉络、哪些是补充解释。

课程顺序与节奏来自原大纲。默认根据个人时间拆分讲次，显示与原单元的对应关系，不把 15 分钟辅导声称为完成 75 分钟原课。也可按原课单元跟学；需要原课完整作业、实验或项目时，先明确用户选择与工作量。保留已有轻量短测、反馈、复习及用户批准后才启动的课程安排，不新增提醒。

每条保存原课名称、机构、教师、版本、常见中英文别名、适合的人群与先修、原始节奏、按顺序组织的单元、原始定位、官方/高校存档链接和核查日期。公开资料无法覆盖完整讲解时，标明证据范围；不能凭大纲编造老师讲过的案例、原话、时戳或指定阅读。实施时若某候选缺乏可核实的原始目录，保留为明确受限的待补条目，不将其计入 README 已收录数量。

## 首次使用与发现

首次安装完成或首次调用且未给出学习方向时，由宿主 Agent 在当前对话简短介绍内置路线，展示 3–5 个跨领域选项并提供完整目录入口。用户可选择一项或自由描述主题。Skill 本身不能在不支持安装后回调的宿主里自动开启对话；README 不作此承诺。不重复打断已有课程或明确请求。

提供轻量、可离线运行的目录列表、检索、详情与课程选择校验命令。检索返回有依据的候选和不确定性，不把模糊的“幸福课”“AI”无条件映射到某一所学校。Agent 负责语义理解，脚本负责有效 ID、版本、来源映射和顺序约束。

## 与现有课程衔接

课程配置可选绑定已选蓝图的不可变快照/摘要及所选范围；计划按天映射原单元。批准前检查 ID、版本、顺序与覆盖；短周期只覆盖部分时明确列出，不宣称完整修完。已启动课程和个人资料模式保留原有语义；改换课程或蓝图版本需要新的、经确认的课程版本。目录更新不能静默改写旧课程。引用说明随本地与云文档输出可见，旧课程不强制迁移。

## README 与真实样张

默认英文和现有九种翻译一起改版，从用户视角介绍“选课程 → 确认个人节奏 → 学习 → 轻测反馈 → 复习”，突出 v3 路线、个人资料学习、十种语言和文档保存。展示实际收录清单与原课链接，不声称学校合作、官方教材或证书。

重新生成六组公开演示的计划与 Day01（PDF 和离线 HTML）：哈佛积极心理学（中文）、CS50x（英文）、MIT 线性代数（日语）、耶鲁音乐聆听（法语）、耶鲁金融市场（西班牙语）、耶鲁死亡哲学（阿拉伯语）。注明原课程版本、节奏改编、来源和示例性质，保留原课定位。教学正文、图注和交互入口使用相应语言；阿拉伯语检查 RTL 与字体。

用实际渲染的样张页面制作一张简约的多文档拼图，放在所有语言 README 最顶部，保留现有透明 Logo。拼图链接到可下载/阅读的真实样例；教学插图有独立来源记录，不把设计示意图伪装为实际生成截图。检查全尺寸和 README 缩小效果。

## 验收与发布

验证精确/别名匹配、歧义/未知课程、先修与范围、原单元顺序、短周期覆盖披露、旧课程兼容、蓝图更新不改变已批准快照，以及资料证据与交付流程。用现实请求独立检验生成结果是否符合选定原课；不以结构校验代替教学质量。
