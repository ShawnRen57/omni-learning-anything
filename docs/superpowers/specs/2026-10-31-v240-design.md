# v2.4.0 material-grounded courses

User approved own-material courses, explicit learning ranges and original-source feedback, and requested a bounded expansion to common books/papers/course formats, with remote publication after tests. Implement inline on codex/v2.4.0 from b28b5fa. Preserve unrelated research drafts and old courses.

Direct readers: text PDF (optional pypdf), UTF-8/UTF-16/GB18030 TXT and Markdown, local/host-fetched HTML, DOCX, EPUB, PPTX and SRT/VTT transcripts. Binary DOC is conditional on an installed trusted converter (antiword/textutil), with exact conversion/dependency failures; RTF may use that same conversion route. No OCR/transcription/DRM bypass, arbitrary downloaded converter or active document execution. Unsupported formats get actionable results. Books/papers/course are content categories, not a promise to parse every file extension.

Import private immutable text snapshots under course/materials before init or after; new file bytes create a new version, never retarget approved courses. Bound file/archive size, entry counts/uncompressed sizes and text; reject unsafe ZIP paths, XML DTD/entities and encrypted EPUB. Preserve locator units: PDF pages, headings/paragraphs, EPUB spine chapters, PPTX slides, transcript timestamps. Record partial/unreadable regions; selecting unreadable PDF pages fails visibly. HTML strips scripts/styles/hidden code, never executes or fetches resources. A website URL is opened by actual host tools and saved to a local snapshot with its canonical public URL; no bundled unrestricted HTTP fetcher.

The agent shows an outline, clarifies ambiguous requested chapters, selects exact unit IDs/headings/pages and excludes unwanted units. Config gains optional materials={policy, selections}, with strict/supplemented/open policies and immutable selection hashes. Retrieval is bounded lexical search of selected units only, not a hidden global RAG index. Each evidence result carries material/version/selection/unit/locator/text. Citation creation validates a literal quote in that evidence unit; document generation and quiz preparation verify references against the approved scope. This is structural provenance, not a semantic truth detector.

Material sources may have no public URL; render title, locator and evidence note as text without inventing links or leaking filesystem paths to cloud documents. Material-mode courses use actual core sources rather than forcing five external links; strict mode disallows unbound external sources, supplemented mode requires material evidence. Legacy courses retain their existing five-link/date contract. Local quotations are not claims of new web verification. Readers must see page/chapter/slide/timestamp locators in delivered source notes. External supplements remain clearly labeled and require actual research.

Integrate into the common document validator/renderers and existing link readback checks, approved config validation and quiz snapshot preparation; never change old manifests, receipts, course destinations or assessment timer exclusions. Agent instructions must offer precise failure guidance, limited scope and private-data handling. Native cloud/UI/citation-clickability and semantic extraction accuracy are claimed only within actually tested scope.

TDD covers real generated file fixtures, malformed/unsafe archives, scoped retrieval, missing page, version immutability, strict/supplemented policy, evidence quote rejection, all local renderers and old regressions. Independently review code/behavior, package and test actual extracted CLI, preserve prior ZIPs; update ten READMEs and release validation, push main/tag and verify downloaded release assets as authorized.
