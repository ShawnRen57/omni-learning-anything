# v4.0.0 validation

The index contains 1,949 entries from the pinned [ChinaTextbook snapshot](https://github.com/TapXWorld/ChinaTextbook/tree/e2b3f62213c77bb8c33c5be355f97625ea1b8b61), including 1,945 student textbooks and four student readers. It covers the primary, junior-secondary and senior-secondary folders of that source. The [Ministry of Education’s compulsory-education directory](https://www.moe.gov.cn/srcsite/A26/s8001/202408/W020250418502592948423.pdf) and the [People’s Education Press revision notes](https://www.pep.com.cn/xw/zt/hd/12/) give context for checking local choices and current editions.

Both secondary books were acquired from local copies of the pinned upstream bytes, with Git blob hashes verified at import. The automated suite also exercises segmented PDFs, wrong editions, wrong pages, altered images and failed downloads. Current textbook files and generated acceptance artifacts stay in the private test archives. The [public samples](../examples/textbooks/README.md) use original figures from historical textbooks with public-domain scan notices.

- The index regenerated byte-for-byte from the pinned tree. All 76 installation ZIP files match the runtime source. The packaged CLI discovered the textbook catalog and resolved a precise formula request under Python `-S`.
- The managed ZIP upgrade from v3.2.0 to v4.0.0 verified the checksum, kept a backup, preserved an external learner config byte-for-byte and retained all 67 university and open-reference pathways. This check used the v4.0.0 updater.
