# v4.0.0 validation

The index contains 1,949 entries from the pinned [ChinaTextbook snapshot](https://github.com/TapXWorld/ChinaTextbook/tree/e2b3f62213c77bb8c33c5be355f97625ea1b8b61), including 1,945 student textbooks and four student readers.
