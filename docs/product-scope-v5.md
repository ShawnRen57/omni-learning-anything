# v5.0 的交付范围与后续优先级

Omni 的交付物是随 Skill 安装的来源目录、能重复使用的生成工具，以及学习者能带走的课程文件。三项能力按下表建设。版本号对应三个功能一起可用的发布。

| 次序 | 可行性与范围 | 验收 |
| --- | --- | --- |
| 1 · 扩充来源 | 单篇 TED 和深度文章可支持一节深入课；教材、书籍和系列课程可支持多周计划。保存原作者或机构、原始入口、资源类型和获取条件，选定后按实际可见的章节或内容编排。 | 在安装包中按机构、主题和类型发现来源；已知条目能打开或绑定。只有书目信息时，标明使用原书所需的条件。 |
| 2 · 教学配图 | 生成前先写下“学生要从图中看出什么”。流程需要方向，比较需要对齐的维度，原物观察需要可定位的细节；照片和教材原图均可通过图注引导观察。 | 在实际输出尺寸检查图中文字、箭头、对齐和图注。请评审者看图回答读图问题并指出依据。答不出或仅凭标题就能答出的图，需重新设计。 |
| 3 · 母语学外语 | 教学语言与目标语言独立设置。按真实情境分阶段编排，逐步减少母语支撑；把讲义、可累积的双向练习卷、答案和可选听力制成文件。 | 检查文字方向、例句与来源、答案隔离、跨课复习和实际可播放的听力。读写用作品或作答验证，听辨用音频，口语用真实发声任务。 |

配图采用图与文字配合、练习在后续课再次提取的设计，参考了美国教育科学研究院的教学指南。外语阶段按可以完成的交际任务组织，参考欧洲委员会的 CEFR 能力描述。是否达到阶段目标，需要看实际作答和任务表现。[IES 教学指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) · [CEFR 能力描述](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors)

## 可直接检查的样例

- [中文学日语的三天课程](../examples/languages/README.md)从进教室时问候、请求重复，一直练到读书会里的三轮独立交流。可先完成[第三天的独立任务](../examples/languages/zh-ja/day03-task.md)，写下自己的回应之后再看参考答案。英语学德语的样例展示同一流程如何适配另一对语言。
- [教学配图样例](../examples/teaching-figures/README.md)包含原图、读图问题、可复现的配图规格及依据。
- [新增的 68 个来源](curated-learning-resources.md)逐项列出原始链接、资源类型、学习切入点和获取条件。

## 后续候选功能

| 建议次序 | 为什么值得做成 Skill | 启动与验收 |
| --- | --- | --- |
| v5.1 · 离线单元学习包 | 一次导出已批准的一周讲义、练习卷、答案册、来源清单及允许分发的音轨，建立相对链接，换设备后能继续使用。适合旅行、家长打印、课堂自学。 | 首先观察是否经常需要分别找讲义、答案和音频。以断网打开、可打印、无答案泄露作验收。 |
| v5.2 · 资源版本与替代来源 | 为经常使用的来源记录章节地址、版本或修订日期；发现断链、课程关停或替换新版时，标出受影响的学习单元和可替代入口。 | 从实际使用最多或经常失效的条目做试点。统计从检索到取得可读原文的成功比例。 |
| v5.3 · 分语种发音与文字难点包 | 收录经核验、带许可的短录音、成对辨听题、文字分解图及答案，同一套内容可反复生成纸面或离线练习。 | 先选择有学习需求和母语审校条件的一对语言。公开发行前逐项核对音频许可、例句和变体。 |

首批外语学习成果以具体任务衡量，例如能读出名字、选择适当的问候语并做简短自我介绍。进度可延伸到下一个场景。课程完成次数不能替代语言水平测试。
