# 现代中小学教材学习样例 / Modern Chinese textbook lessons

## 可以这样提问

- 小学一年级 · 科学：用青岛版小学一年级下册科学，带我学《认识空气》。我刚上一年级，用短句和生活里的例子。
- 小学三年级 · 数学：帮我用人教版小学三年级上册数学学长方形的周长公式。先用教材原图讲明白为什么要乘 2。
- 初中七年级 · 音乐：用湘文艺版七年级下册《音乐》第一单元教我读四四拍，带我区分拍子和节奏。
- 初中七年级 · 地理：用商务星图版七年级上册地理第一章，讲清楚怎样从赤道半径和极半径判断地球形状。
- 高中 · 通用技术：用粤教粤科版高中通用技术选择性必修 8 第一章，带我读职业结构图，并练习区分描述和因果解释。
