# Textbook learning samples / 教材学习样例

These two short lessons demonstrate a concept-sized scope, age-appropriate explanation, and an original textbook illustration. The public examples use historical Chinese textbooks whose scans are marked public domain by Wikimedia Commons. The modern K–12 index is a separate collection.
