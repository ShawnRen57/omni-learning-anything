# Learn a foreign language through your own language

**中文 → 日语。** 三天，每天 12 分钟。先在教室里问候和道谢，接着练习没听清时怎样请人重复，最后在新的读书会场景里独立完成三轮交流。每一天都有一份可以带走的回忆练习，答案单独存放。[查看三天计划](zh-ja/plan.md) · [下载离线 HTML 计划](zh-ja/plan.html)
