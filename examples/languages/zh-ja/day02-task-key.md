# 请求重复与确认 · 参考回应

もういちど、お願いします。／わかりました。

- 先表达请对方重复的意图，可以加上礼貌的すみません。
- 再次得到信息并听懂后，才确认自己明白了。

另一个常见写法是「もう一度、お願いします」。对方还没有重复时，先说「わかりました」会给人已经明白的印象。
