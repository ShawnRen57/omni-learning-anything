# 第一天 · 听懂课堂里的两句话

打开国际交流基金会《彩》入门第 1 课的 MP3 页面，选择音轨 **01-20**，先听一遍。想一想：两个人是在早上初次见面，还是在回应别人的帮助？再听一次，记下让你作出判断的日语词。手机和电脑都可以通过页面播放器收听。[打开第 1 课原声](https://www.irodori.jpf.go.jp/en/starter/audio/lesson01.html)

完成后，在同一课的 PDF 中查找音轨编号 **01-20**，对照原文检查。也可以回到第一天的讲义比较两种情景。[查看原课 PDF](https://www.irodori.jpf.go.jp/assets/data/starter/pdf/X_L01.pdf) · [回到第一天](../day01.md)
