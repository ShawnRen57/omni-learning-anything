# 第一次独立完成见面交流 · 参考回应

① おはようございます。ミナです。　② もういちど、お願いします。　③ ありがとうございます。

- 用合乎初次见面或早晨场景的问候，再用给定活动名作自我介绍。
- 漏听后主动要求重复，保留礼貌语气。
- 在收到帮助后作出合理收尾，可以确认已经听懂，也可以道谢。

第一轮也可以用「はじめまして」开场。第三轮若写「わかりました」，应当是在对方重复之后。三个场景都符合时，记为此次完成书面任务；需要提示的那一轮，明天单独重试一次。
